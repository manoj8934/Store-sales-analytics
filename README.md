# Store-sales-analytics
A data analytics project exploring store sales data using MySQL and Power BI.

Project Overview

The purpose of this project is to analyze sales data, identify business trends, and support data-driven decision-making.

Tools Used

- MySQL: SQL queries for data analysis
- Power BI: Dashboard creation and data visualization
- CSV: Source dataset

Project Files

- "README.md" — Project documentation
- "Insights.md" — Business insights and recommendations
- SQL file — Queries used for sales analysis
- CSV file — Dataset used in the project
- Power BI file — Interactive dashboard
